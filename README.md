# Deejay Zak

Premium bilingual (EL/EN) website for Deejay Zak — professional DJ based in Crete, Greece.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/el` by default.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — start production server
- `npm run lint` — ESLint

## Content

Artist data, services, support acts, gallery placeholders, events, and translations live under `src/data/`.

Replace placeholders (photos, tracks, events, social URLs) when real assets are available. Do not invent facts.
